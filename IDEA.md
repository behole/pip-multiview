## Masonry multiview (2026-09-02)
User-controlled masonry grid of viewports. Watch 3 vertical videos at once instead of one centered. Per-pane: audio on/off, play/pause. Modular grid of viewports, drag/resize panes.
Note: YT TV shipped custom multiview Apr 2026 (live TV only, 4-up) — this is the VOD/vertical/arbitrary-URL white space.
Stack hints: embed API grid, localhost reverse-proxy for dev, Document PiP for pop-out. Desktop shell (Tauri) if it outgrows the browser.
